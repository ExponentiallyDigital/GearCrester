# GearCrester Vision

GearCrester helps players understand what gear can be upgraded with crests,
what crests they have, and what the optimal upgrade order is based on slot
priority and crest availability.

It does not:

- simulate DPS
- evaluate stat weights
- replace AMR or Pawn
- recommend BIS items

It focuses on:

- clarity
- upgrade visibility
- crest planning
- modular architecture
